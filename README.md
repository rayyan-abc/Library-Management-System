Project Overview

Library Management System is a Python-based application designed to manage books and borrowing records.

The application uses Object-Oriented Programming, JSON file handling, exception handling, and the datetime module.

All data is permanently stored in JSON files.

 Features

- Add new books
- View all books
- Search books by ID or title
- Update book information
- Delete books
- Borrow books
- Return books
- View borrowed books
- Generate library reports
- JSON data persistence
- Input validation
- Exception handling

 Technologies Used

- Python
- Object-Oriented Programming
- JSON
- datetime
- collections.Counter
- File Handling
- Exception Handling
- Git & GitHub

How to Run:

python main.py

Data Storage:

The application uses two JSON files.

books.json:

Stores all book information.

borrow_records.json:

Stores all borrowing records.

library_report.txt:

Stores the generated library report.

The generated report contains:

Total number of books

Total available books

Total borrowed books

Number of books in each category

Most borrowed book

Number of active borrowers

Timestamp of report generation
